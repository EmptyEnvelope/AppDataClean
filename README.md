# AppDataClean

项目基于https://github.com/Hermesiss/appdata-cleaner 项目的代码修改而来

清理C盘临时文件，包括appdata,programdata里的残留文件以及c盘chromium系软件的临时文件、微软临时下载文件、微软临时文件夹
